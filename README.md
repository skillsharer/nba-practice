# nba-practice

## Exploratiory Data Analysis:
My approach is:
1. What we predict, what is `y` in this case and what it's distribution.
2. Plot feature vs. outcome `y`, how each feature contributes to `y`. For numerical data we can use box plots, histograms for example, for categorical data we can use bar charts.
3. Drop those features which we don't know at classification time.
4. Plot feature comparisons.
